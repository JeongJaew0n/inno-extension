# 아마란스 통합알림 새로고침·인증번호 복사

- 상태: Active
- 최종 갱신일: 2026-08-13
- 대상 버전: 0.2.x

## 한 줄 요약

아마란스 통합알림의 `전체` 목록을 즉시 갱신하고, 인증 메일의 4~6자리 인증번호를 한 번에 복사한다.

## 배경과 사용자 문제

통합알림에는 별도 새로고침 버튼이 없어 새 메일을 확인하려면 다른 분류 탭을 열었다가 `전체`로
돌아와야 한다. 인증 메일을 받았을 때는 제목이나 본문에서 번호를 직접 선택해 복사해야 한다.

이 기능은 아마란스가 이미 제공하는 알림 갱신 흐름을 화면 안에서 바로 실행하고, 인증번호를
명시적 사용자 클릭으로만 복사해 반복 단계를 줄인다.

## 목표

- `전체` 알림을 팝업을 닫거나 다른 화면으로 이동하지 않고 갱신한다.
- 인증 메일의 4~6자리 번호를 선행 0까지 보존해 복사한다.
- 날짜, 연도, 업무번호 같은 일반 숫자에 복사 버튼이 생기는 오탐을 줄인다.
- 알림 목록이 다시 그려져도 버튼을 중복 없이 복구한다.
- 기능 OFF 또는 아마란스 서비스 OFF 시 확장이 만든 UI를 남기지 않는다.

## 비목표

- 메일 서버나 아마란스 내부 알림 API를 직접 호출하지 않는다.
- 알림을 주기적으로 자동 갱신하지 않는다.
- 메일을 열거나 읽음 처리하거나 삭제하지 않는다.
- 인증번호를 자동으로 복사하거나 다른 입력란에 자동 입력하지 않는다.
- 인증번호의 유효성, 발급자, 만료 시간을 검증하지 않는다.
- 메일 이외의 업무보고, 전자결재, 일정 알림에서 숫자를 추출하지 않는다.

## 대상 사용자와 적용 범위

- 서비스: 아마란스
- 사이트: `https://gw.innogrid.com`
- 화면: 통합알림 팝업의 `전체` 탭
- 대상 알림: 출처가 `[메일]`로 표시된 알림

다른 분류 탭을 보고 있거나 통합알림 팝업이 닫혀 있으면 새 UI를 표시하지 않는다.

## 사용자 경험과 행동 계약

### 새로고침

1. 사용자가 통합알림을 열고 `전체` 탭을 선택한다.
2. `오늘` 날짜 행의 최우측에 `새로고침` 버튼이 표시된다.
3. 버튼을 누르면 `갱신 중…` 상태가 표시되고 중복 클릭이 차단된다.
4. 아마란스의 기존 분류 전환 동작을 통해 `전체` 목록을 다시 불러온다.
5. 완료되면 `갱신됨`, 제한 시간 안에 복구되지 않으면 `갱신 실패`를 잠시 표시한다.

새로고침은 팝업을 닫거나 현재 아마란스 업무 화면을 바꾸지 않는다.

### 인증번호 복사

1. `[메일]` 알림의 제목과 본문에 인증 관련 문맥과 4~6자리 번호가 함께 있으면 제목 행에
   `복사` 버튼이 표시된다.
2. 번호가 제목에 있으면 제목의 번호 바로 오른쪽에 표시한다. 번호가 본문에만 있으면 제목 끝에
   인증번호 복사 버튼을 표시한다.
3. 사용자가 버튼을 누르면 번호를 문자열 그대로 복사하고 `복사됨` 피드백을 표시한다.
4. 복사 버튼 클릭은 원래 알림 클릭으로 전달되지 않으므로 메일을 열거나 읽음 상태를 바꾸지 않는다.

같은 번호가 제목과 본문에 반복돼도 알림 하나당 버튼은 하나만 표시한다.

## 인증번호 판별 계약

- 다른 숫자와 붙지 않은 4~6자리 연속 숫자만 후보로 사용한다.
- `039911`처럼 0으로 시작하는 번호를 문자열 그대로 유지한다.
- 같은 메일의 제목이나 본문에 다음과 같은 인증 문맥이 있어야 한다.
  - 영문 예: `AuthCode`, `authentication`, `verification`, `OTP`, `token code`, `passcode`
  - 한글 예: `인증`, `인증번호`, `인증 코드`, `보안코드`, `일회용`
- 제목의 첫 번째 후보를 우선하고, 제목에 후보가 없으면 본문의 첫 번째 후보를 사용한다.
- `[WBlock] 메일 리스트 - 2026/08/13`처럼 인증 문맥이 없는 날짜와 연도는 제외한다.
- 인증 문맥이 없는 일반 숫자는 사용자가 요청한 자리수와 같아도 복사 버튼을 표시하지 않는다.

## 설정과 기본값

- 기능 기본값: ON
- 추가 설정값: 없음
- 아마란스 서비스 전체 토글과 기능 토글을 모두 따른다.

기능을 꺼도 아마란스의 원래 알림과 읽음 상태에는 영향을 주지 않는다.

## 기술적 맥락과 제약

- 아마란스는 React SPA이며 팝업을 다시 열거나 분류 탭을 바꾸면 알림 목록 DOM이 교체된다.
- 확장은 화면 변경을 감지해 현재 조건에 맞는 버튼을 한 번만 복구해야 한다.
- 새로고침은 비공개 API가 아니라 아마란스가 제공하는 기존 분류 탭 동작에 위임한다.
- 통합알림과 알림 항목의 식별은 외부 서비스 DOM 구조에 의존하므로 화면 개편 시 재검증이 필요하다.
- 기능을 위해 새로운 Chrome 권한, 백그라운드 작업, 외부 서버 통신을 추가하지 않는다.

## 보안과 개인정보

- 메일 제목과 알림 미리보기는 현재 화면 안에서만 검사하며 별도 저장하거나 외부로 전송하지 않는다.
- 인증번호는 사용자가 복사 버튼을 누른 경우에만 로컬 클립보드에 기록한다.
- 쿠키, 세션 토큰, 메일 계정 인증 정보에 접근하지 않는다.
- 실제 인증번호를 로그나 설정에 저장하지 않는다.

## 주요 결정과 트레이드오프

### 내부 API 대신 기존 탭 동작 사용

통합알림의 내부 네트워크 계약은 공개 API가 아니며 인증과 변경 위험이 크다. 실제 화면에서 분류
탭 왕복으로 갱신되는 동작을 확인했으므로 사이트의 기존 처리에 위임한다. 이 방식은 잠깐의 탭
상태 전환이 필요하지만 현재 업무 화면과 인증 경계를 침범하지 않는다.

### 자리수만 보지 않고 인증 문맥 요구

메일 목록에는 연도와 시간이 자주 등장한다. 자리수만 적용하면 `2026` 같은 일반 숫자를
인증번호로 오인하므로 인증 관련 문맥을 함께 요구한다. 새로운 발급자가 문맥 키워드를 다르게
사용하면 버튼이 누락될 수 있으며, 실제 사례가 확인되면 키워드 계약을 확장한다.

### 하나의 기능으로 제공

새로고침과 복사는 같은 통합알림 팝업과 재렌더 생명주기를 공유하고 별도 설정도 필요하지 않다.
첫 버전에서는 `통합알림 새로고침·인증번호 복사` 기능 하나로 켜고 끈다.

## 실패와 복구 동작

- 통합알림 팝업, `전체` 탭, `오늘` 행을 찾지 못하면 새로고침 버튼을 표시하지 않는다.
- 분류 탭 왕복이 제한 시간 안에 완료되지 않으면 `갱신 실패`를 표시하고 원래 알림 UI는 유지한다.
- 번호 복사에 실패하면 `실패` 피드백을 표시하며 원래 메일 알림은 그대로 사용할 수 있다.
- 알림 목록 재렌더로 버튼이 제거되면 대상 조건을 다시 확인해 한 번만 복구한다.
- 기능 또는 서비스가 꺼지면 확장이 추가한 버튼과 스타일을 제거한다.

## 수용 기준

- `전체` 탭의 `오늘` 행 최우측에 새로고침 버튼이 보인다.
- 새로고침 후에도 `전체` 탭으로 돌아오며 목록과 인증번호 버튼이 중복 없이 복구된다.
- 인증 문맥이 있는 4자리, 5자리, 6자리 번호를 복사할 수 있다.
- 선행 0이 있는 번호가 손실 없이 복사된다.
- 인증 문맥이 없는 연도, 긴 숫자의 일부, 메일 이외 알림에는 복사 버튼이 생기지 않는다.
- 복사 버튼을 눌러도 메일 알림이 열리지 않는다.
- 기능 OFF 후 버튼이 제거되고 ON 후 다시 나타난다.
- typecheck, unit test, production build가 성공한다.

## 알려진 리스크와 열린 질문

- 아마란스가 통합알림 ID, 분류 구조, 날짜 행, 메일 제목 구조를 변경하면 버튼이 표시되지 않을 수 있다.
- 알려지지 않은 인증 메일 표현은 문맥 키워드에 포함되지 않아 번호를 감지하지 못할 수 있다.
- `메일 → 전체` 전환이 향후 갱신을 발생시키지 않게 바뀌면 새로고침 전략을 다시 검토해야 한다.
- 현재는 알림 하나에서 첫 번째 인증번호만 지원한다. 한 메일에 서로 다른 인증번호가 여러 개
  표시되는 사례가 생기면 선택 규칙을 재검토한다.

## 변경 이력

- 2026-08-13: 통합알림 `전체` 탭에 명시적 새로고침과 인증번호 복사 기능을 추가했다. 내부 API
  대신 기존 분류 탭 갱신 동작을 사용하고, 연도 오탐을 막기 위해 인증 문맥 조건을 함께 적용했다.
