# Jira 설명 Markdown 복사

- 상태: Active
- 최종 갱신일: 2026-09-17
- 내부 기능 ID: `descriptionMarkdownCopy`
- 기본값: ON

## 한 줄 요약

업무 **설명** 본문을 제목·표·목록·링크까지 Markdown으로 바꿔 클립보드에 넣는다.

## 배경과 사용자 문제

설명을 다른 문서로 옮길 때 화면에서 긁으면 표가 한 줄로 뭉개지고 링크가 사라진다. 같은 문제를
Confluence 문서 본문에서 먼저 풀었다.

**Jira 설명 읽기 화면은 Confluence 문서 본문과 같은 `.ak-renderer-document`를 쓴다.** 변환기를
그대로 쓸 수 있다.

## 적용 범위와 활성 조건

- Jira 서비스와 이 기능이 모두 ON일 때 동작한다. **기본값은 ON이다.**
- 대상은 업무 **설명** 하나다.
- 본문은 `[data-testid="issue.views.field.rich-text.description"]` **안에서만** 찾는다.

> **댓글도 같은 렌더러를 쓴다.** 문서 전체에서 찾으면 댓글 본문을 복사하게 된다.

- **편집 중에도 동작한다.** 다만 값을 가져오는 곳이 다르다 — 아래 참조.
- 설명이 비어 있으면 버튼을 붙이지 않는다.

## 사용자 경험

`설명` 라벨 오른쪽에 `Markdown 복사` 버튼이 붙는다. 누르면 본문 전체를 Markdown 평문으로 복사한다.

| 상태 | 라벨 |
| --- | --- |
| 기본 | `Markdown 복사` |
| 진행 | `복사 중` |
| 성공 | `복사됨` (1.2초 뒤 기본으로) |
| 실패 | `복사 실패` |

## 동작 계약

### 읽기 중과 편집 중의 출처가 다르다

| 상태 | 출처 |
| --- | --- |
| 읽기 | `.ak-renderer-document` 를 HTML 태그째로 옮긴다 |
| **편집** | **ProseMirror 에서 ADF 를 직접 읽어** 옮긴다 |

편집기 DOM 을 긁지 않는 이유는 둘이다. 코드블럭이 CodeMirror 라 렌더러 진입점이 아예 없고
(실측 0개), **30줄 안팎까지만 렌더돼 긴 블록은 내용이 사라진다.**

편집 중에는 Markdown 에 대응물이 없는 노드가 섞인다. **텍스트로 떨어뜨린다.**

| 노드 | 처리 |
| --- | --- |
| 매크로(Mermaid 등) | 버린다. 원본 코드블럭이 옆에 남는다 |
| `expand`·`panel`·레이아웃 | 껍데기를 벗기고 내용만 |
| 상태·멘션·날짜·이모지 | 글자로 |
| 첨부 이미지 | `(이미지 첨부)` — 밖에서 쓸 수 없는 참조를 넣지 않는다 |

### 그 밖

- 클립보드에는 **평문 Markdown만** 넣는다. 리치 텍스트는 넣지 않는다.
- 클릭 시점에 본문을 **다시 찾는다.** 그 사이 다른 업무로 바뀌었을 수 있다.
- 변환은 화면을 바꾸지 않는다. 읽기만 한다.

## 설정과 기본값

| 항목 | 값 |
| --- | --- |
| 기능 기본값 | **ON** |
| 추가 옵션 | 없음 |

## 실패와 복구

- 본문을 찾지 못하면 `복사 실패`를 보여주고 콘솔에 남긴다. **Jira 기본 동작은 그대로다.**
- 라벨 줄 구조가 바뀌면 버튼이 라벨 아래 줄에 놓인다. 동작은 유지된다.

## 수용 기준

- 표·링크·목록이 든 설명이 Markdown 구조를 유지한 채 복사된다.
- **댓글 본문이 섞이지 않는다.**
- 편집 중에도 복사되고, 긴 코드블럭이 잘리지 않는다.
- 다른 업무로 바꾸면 버튼이 그 업무의 설명을 복사한다.
- 기능이 OFF면 아무것도 주입되지 않는다.

## 알려진 리스크와 열린 질문

- **댓글이 달린 이슈에서 실제로 확인하지 못했다.** 측정한 이슈에는 렌더러가 설명 것 하나뿐이었다.
- 전체 화면 업무 보기(`/browse/...`)의 구조를 확인하지 않았다.
- 라벨 안쪽 flex 줄이 해시 클래스라 `firstElementChild`에 기대는 부분이 있다.

## 변경 이력

- 2026-09-18: 편집 중에도 복사되게 했다. ADF 를 직접 읽는 경로를 더했다.
- 2026-09-17: 기능을 추가했다. Confluence 본문 Markdown 복사의 변환기를 `platform/editor/`로
  공용화해 Jira 설명에 붙였다. 기본값 ON.
