# 아마란스 헤더 출퇴근 버튼

- 상태: Active
- 최종 갱신일: 2026-08-13
- 대상 버전: 0.2.x

## 한 줄 요약

아마란스의 원본 출근·퇴근 동작을 헤더 가까이에서 실행하고, 근무시간 위젯에 기록된 오늘 출근 시각으로 인사말을 한 번에 복사한다.

## 배경과 사용자 문제

아마란스의 원본 출퇴근 버튼은 화면에서 바로 보이지 않아 매일 반복해서 찾아야 한다. 출근 처리
후 메신저 등에 출근 시각을 공유할 때도 기록된 출근 시각을 확인하고 문구를 직접 작성해야 한다.

이 기능은 원본 근태 처리 책임은 아마란스에 남긴 채 접근하기 쉬운 헤더 버튼을 제공하고,
별도의 명시적 버튼으로 출근 인사말 작성 단계를 줄인다.

## 목표

- 스크롤하지 않고 헤더 가까이에서 출근·퇴근 동작을 실행한다.
- 원본 버튼의 현재 활성 상태를 헤더 버튼에도 보여 준다.
- 출근 버튼 바로 아래에서 오늘 기록된 출근 시각의 인사말을 복사한다.
- 화면이 다시 그려져도 버튼을 중복 없이 복구한다.

## 비목표

- 출근·퇴근을 예약하거나 자동 실행하지 않는다.
- 인사말 복사와 동시에 출근 처리를 실행하지 않는다.
- 인사말을 메신저나 다른 서비스에 자동 전송하지 않는다.
- 출근 시각을 아마란스 API나 서버 근태 이력에서 조회하지 않는다. 화면에 이미 그려진 값만 읽는다.
- 인사말 형식을 사용자가 설정하는 기능은 현재 범위에 포함하지 않는다.

## 대상 사용자와 적용 범위

- 서비스: 아마란스
- 사이트: `https://gw.innogrid.com`
- 화면: 원본 출퇴근 버튼과 헤더 알림 영역이 함께 존재하는 화면

원본 출퇴근 버튼을 찾을 수 없는 화면에서는 헤더 버튼이 보이더라도 실제 근태 처리를 임의로
대체하지 않는다.

## 사용자 경험과 행동 계약

### 출근·퇴근

1. 헤더 가까이에 `출근`, `퇴근` 버튼이 표시된다.
2. 사용자가 버튼을 누르면 대응하는 아마란스 원본 버튼의 동작을 그대로 실행한다.
3. 원본 버튼의 활성 상태가 바뀌면 헤더 버튼의 시각적 상태도 맞춰진다.

확장은 근태 API를 직접 호출하거나 성공을 추정하지 않는다. 실제 처리와 오류 안내는 원본
아마란스 화면이 담당한다.

### 인사말 복사

1. `출근` 버튼 바로 아래에 `인사말 복사` 버튼이 표시된다.
2. 사용자가 버튼을 누른 순간 브라우저 현지 시간의 시와 분을 읽는다.
3. `<시>시 <분>분 출근입니다.` 형식의 문구를 클립보드에 복사한다.
4. 복사 성공 시 `복사됨`, 실패 시 `실패`를 잠시 표시한 뒤 원래 문구로 돌아간다.

예시는 다음과 같다.

- 오전 9시 5분: `9시 5분 출근입니다.`
- 오후 6시 정각: `18시 0분 출근입니다.`

시간과 분에는 앞자리 0을 붙이지 않는다. 화면에 `08:58`로 표시돼 있으면 `8시 58분 출근입니다.`가 된다.

인사말 복사는 출근 처리와 독립적이다. 다만 복사할 시각은 근무시간 위젯의 오늘 출근 기록에서
읽으므로, 출근 기록이 없으면 문구를 만들지 않고 버튼에 `출근 기록 없음`을 표시한다.

## 설정과 기본값

- 기능 기본값: ON
- 인사말 형식: 고정
- 시간 기준: 근무시간 위젯에 표시된 오늘 출근 시각
- 저장 데이터: 없음

기능 또는 아마란스 서비스 전체를 끄면 출근·퇴근·인사말 복사 UI를 함께 제거한다.

## 기술적 맥락과 제약

- 근태 처리는 원본 아마란스 버튼의 클릭 동작에 위임한다.
- 아마란스는 SPA이므로 헤더나 원본 버튼이 다시 생성될 수 있으며, 확장 UI도 현재 DOM에 맞춰
  중복 없이 복구해야 한다.
- 인사말 시각은 근무시간 위젯 `.myWorkTime`의 오늘 행에서 읽는다. 확장이 버튼을 붙이는
  `.noti-details`가 이 위젯 안에 있으므로, 버튼이 존재하면 출근 기록도 같은 화면에 있다.
- 오늘 행은 `.myWork-date .badge`의 `오늘` 표기로 판별한다. 위젯은 지난 날짜 행도 함께 보여
  주므로 배지를 찾지 못하면 첫 행으로 대체하지 않는다. 대체하면 어제 시각을 복사하게 된다.
- 지난 날짜 행의 값은 `09:56(09:56)`처럼 괄호가 붙은 변형으로 나타난다. 앞쪽 시각을 확정
  값으로 사용한다.
- 아직 등록되지 않은 항목은 `미등록`으로 표시된다.
- 기능을 위해 새로운 Chrome 권한이나 아마란스 API 접근을 추가하지 않는다.

## 보안과 개인정보

- 근태 정보나 복사한 인사말을 별도 저장하거나 외부로 전송하지 않는다.
- 인사말은 사용자의 명시적 클릭이 있을 때만 로컬 클립보드에 기록한다.
- 인사말 복사는 원본 출근·퇴근 상태를 변경하지 않는다.

## 주요 결정과 트레이드오프

### 출근 버튼 아래에 배치

인사말은 출근과 연관된 보조 동작이므로 별도 기능 카드로 분리하지 않고 출근 버튼의 바로 아래에
둔다. 출근 처리와 복사는 서로 다른 버튼으로 유지해 실수로 근태를 처리하거나 문구를 복사하지
않게 한다.

### 화면에 기록된 출근 시각 사용

초기 구현은 클릭 순간의 브라우저 시간을 사용했다. 비공개 API와 인증 계약을 추가하지 않기 위한
선택이었다. 그러나 출근 처리와 인사말 복사 사이에 시간이 흐르면 실제 근태와 다른 문구가
만들어진다. 실측에서도 기록은 `08:58`인데 복사 시점이 `9시 7분`이라 9분 차이가 발생했다.

근무시간 위젯이 오늘 출근 시각을 이미 화면에 표시하고 있으므로, API를 추가하지 않고 DOM에서
읽어 이 문제를 해결한다. 원래 결정이 피하려던 비용은 그대로 피하면서 정확도만 얻는다.

### 기록이 없으면 복사하지 않음

출근 기록을 읽지 못했을 때 현재 시각으로 대체하지 않는다. 대체하면 사용자가 눈치채지 못한 채
실제 근태와 다른 문구를 공유하게 되며, 이는 이 변경이 없애려는 문제 그 자체다. 대신 버튼에
`출근 기록 없음`을 표시해 사용자가 상황을 알 수 있게 한다.

### 고정 문구 사용

현재 요청은 `n시 n분 출근입니다.` 한 가지 형식이다. 설정 UI와 템플릿 문법을 추가하지 않아
기능을 단순하게 유지한다.

## 실패와 복구 동작

- 원본 출퇴근 버튼을 찾지 못하면 근태 처리를 대신 실행하지 않는다.
- 클립보드 복사에 실패하면 `실패` 피드백을 표시하며 출근 상태는 변경하지 않는다.
- SPA 재렌더로 헤더 버튼이 제거되면 대상 영역을 다시 찾았을 때 한 세트만 복구한다.
- 기능 OFF 시 확장이 만든 버튼과 스타일을 제거한다.

## 수용 기준

- 헤더의 출근 버튼 바로 아래에 `인사말 복사` 버튼이 보인다.
- 오전 9시 5분에 누르면 `9시 5분 출근입니다.`가 복사된다.
- 오후 시간은 24시간제로 표현되고 시와 분에 앞자리 0이 붙지 않는다.
- 복사 버튼을 눌러도 원본 출근 버튼이 클릭되지 않는다.
- 기존 출근·퇴근 버튼의 클릭 위임과 활성 상태 표시가 유지된다.
- 화면 재렌더와 기능 OFF/ON 후 버튼이 중복 없이 제거·복구된다.
- typecheck, unit test, production build가 성공한다.

## 알려진 리스크와 열린 질문

- 사용자 기기의 시계나 시간대가 실제 근태 서버와 다르면 복사 문구와 근태 기록이 다를 수 있다.
- 향후 `오전/오후`, 두 자리 분, 사용자 이름 포함 등 다른 문구 형식 요구가 생기면 설정 범위를
  별도로 결정해야 한다.
- 아마란스가 원본 근태 버튼이나 헤더 구조를 변경하면 배치와 클릭 위임을 재검증해야 한다.

## 변경 이력

- 2026-07-09: 화면 아래의 원본 출근·퇴근 버튼을 헤더 가까이에서 실행하는 기능을 추가했다.
- 2026-08-13: 출근 버튼 아래에 클릭 순간의 현지 시각으로 `n시 n분 출근입니다.`를 복사하는
  `인사말 복사` 버튼과 성공·실패 피드백을 추가했다.
- 2026-08-26: 인사말 시각 기준을 클릭 순간의 브라우저 시간에서 근무시간 위젯에 기록된 오늘 출근 시각으로 바꿨다. 출근 기록이 없으면 현재 시각으로 대체하지 않고 `출근 기록 없음`을 표시한다.
