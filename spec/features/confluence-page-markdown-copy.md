# Confluence 문서 본문 Markdown 복사

- 상태: Active
- 최종 갱신일: 2026-08-07
- 대상 버전: 0.2.x

## 한 줄 요약

Confluence 문서 조회 화면에서 버튼 한 번으로 제목과 댓글을 제외한 본문을 Markdown 텍스트로 복사한다.

## 배경과 사용자 문제

Confluence 문서의 내용을 AI 도구, 코드 저장소, 메신저처럼 Markdown을 사용하는 다른 작업 공간으로 옮길 때 브라우저의 일반 복사는 화면용 서식과 불필요한 UI를 함께 포함하거나 제목 계층, 표, 코드 블록 구조를 잃는다. 사용자는 본문을 복사한 뒤 반복적으로 형식을 정리해야 한다.

이 기능은 현재 보고 있는 문서 본문을 재사용 가능한 Markdown으로 변환해 클립보드에 넣어 후처리 비용을 줄인다.

## 목표

- 문서 조회 화면에서 복사 기능을 쉽게 발견하게 한다.
- 문서 제목, 작성자, 댓글, 탐색 UI를 제외하고 본문만 복사한다.
- 일반 문서에서 자주 쓰는 제목, 문단, 목록, 표, 코드 블록, 링크와 기본 강조 형식을 Markdown으로 보존한다.
- 사용자가 복사 진행, 성공, 실패 여부를 버튼에서 바로 알 수 있게 한다.
- 문서 내용이나 인증 정보를 외부 서버에 전송하지 않는다.

## 비목표

- 문서 제목이나 원본 URL을 복사 결과에 자동으로 포함하지 않는다.
- Confluence 편집 화면의 작성 중 내용을 지원하지 않는다.
- Confluence REST API나 세션 쿠키를 직접 사용하지 않는다.
- 모든 Confluence 매크로와 서드파티 앱을 손실 없이 변환하는 범용 내보내기 도구를 목표로 하지 않는다.
- 복사한 Markdown을 파일로 저장하거나 외부 서비스에 자동 전송하지 않는다.

## 서비스, 대상 사이트, 적용 조건

- 서비스: `Confluence`
- 사이트: `https://pms-innogrid.atlassian.net/wiki/*`
- 대상: space 아래의 문서 조회 화면
- 기본값: Confluence 서비스 ON, 본문 Markdown 복사 기능 ON

기능은 다음 조건을 모두 만족할 때만 표시한다.

- Confluence 서비스 전체 기능이 ON이다.
- 본문 Markdown 복사 기능이 ON이다.
- 현재 URL이 문서 조회 주소다.
- 화면에서 렌더링된 본문 영역을 찾을 수 있다.

## 사용자 경험과 행동 계약

문서 조회 화면의 상단 작업 영역 오른쪽 끝에 복사 아이콘과 `본문 Markdown 복사` 문구가 있는 버튼을 표시한다. 기본 작업 영역을 아직 찾지 못했지만 본문이 준비된 경우에는 문서 내용 위쪽 오른쪽에 임시로 표시할 수 있으며, 기본 작업 영역이 준비되면 그 위치로 이동한다.

사용자가 버튼을 누르면 다음 순서로 상태를 표시한다.

```text
본문 Markdown 복사 → 복사 중 → 복사됨
                         └→ 복사 실패
```

성공 또는 실패 표시는 잠시 유지한 뒤 기본 문구로 돌아간다. 여러 차례 화면을 다시 렌더링하거나 문서 사이를 이동해도 버튼이 중복 생성되지 않아야 한다.

복사 대상은 현재 화면에 렌더링된 본문이다. 다음 항목은 결과에서 제외한다.

- 문서 제목과 작성자·수정 정보
- 상단 탐색과 문서 작업 버튼
- 제목 앵커, 코드 블록 복사, 표 정렬처럼 Confluence가 본문 위에 추가한 조작 UI
- 댓글과 추천 문서

## Markdown 출력 계약

클립보드에는 UTF-8 일반 텍스트 Markdown을 기록한다. 브라우저나 붙여넣기 대상에 따라 달라지는 별도의 HTML payload는 제공하지 않는다.

지원하는 기본 변환은 다음과 같다.

| Confluence 본문 요소 | Markdown 결과 |
| --- | --- |
| 제목 | `#`부터 `######`까지의 ATX 제목 |
| 문단과 줄바꿈 | 문단 사이 빈 줄과 필요한 줄바꿈 |
| 순서 없는 목록 | `-` 목록과 중첩 들여쓰기 |
| 순서 있는 목록 | 숫자 목록과 중첩 들여쓰기 |
| 표 | GitHub Flavored Markdown 표 |
| 코드 블록 | 언어가 있으면 언어명을 포함한 fenced code block |
| 인라인 코드 | backtick code span |
| 굵게·기울임·취소선 | 기본 Markdown 강조 문법 |
| 링크와 이미지 | 가능한 경우 절대 URL을 사용하는 Markdown 링크와 이미지 |
| 인용과 구분선 | blockquote와 horizontal rule |

본문 앞뒤의 불필요한 공백과 과도한 빈 줄은 정리하되 사용자가 작성한 텍스트 자체를 요약하거나 번역하지 않는다.

## 기술적 맥락과 결정

### 렌더링된 DOM을 정본으로 사용

현재 제품은 사내 API와 인증 정보를 직접 다루지 않고 로그인된 화면의 DOM을 활용하는 원칙을 따른다. 이 기능도 현재 사용자에게 보이는 문서 본문을 읽어 변환한다.

이 선택은 추가 API 권한과 Confluence 저장 형식 변환을 피하고 현재 문서 버전과 화면 상태를 그대로 사용한다는 장점이 있다. 반면 Confluence의 DOM 구조가 바뀌면 본문 탐지나 변환이 중단될 수 있으므로 실제 사이트 확인과 selector 유지보수가 필요하다.

### 외부 변환 의존성을 추가하지 않음

첫 버전은 제품이 지원한다고 명시한 기본 요소를 로컬 코드로 변환한다. 번들 크기와 새 공급망 의존성을 늘리지 않지만, 범용 HTML-to-Markdown 라이브러리보다 지원 요소가 제한적이다. 매크로 지원 요구가 커지면 검증된 변환 라이브러리 도입을 다시 판단한다.

### Confluence를 독립 서비스로 분리

Jira와 같은 Atlassian origin을 사용하지만 URL 범위, 문서 모델, DOM과 사용자 작업이 다르므로 Popup과 실행 lifecycle에서는 별도 Confluence 서비스로 제공한다. 한 서비스의 DOM 변경이 다른 서비스 기능을 깨뜨리지 않아야 한다.

## 보안과 개인정보

- 문서 본문은 사용자가 버튼을 누른 순간 현재 탭에서만 읽는다.
- 변환 결과는 사용자의 로컬 클립보드에만 기록한다.
- 본문, 쿠키, 토큰을 확장 프로그램 저장소나 외부 서버로 전송하지 않는다.
- 클립보드 쓰기는 사용자의 직접 클릭 이벤트에서만 수행한다.
- 기능을 끄면 확장이 만든 버튼을 제거하며 원본 문서를 변경하지 않는다.

## 실패와 복구

- 본문을 찾지 못하면 버튼을 표시하지 않고 Confluence 원본 화면에는 영향을 주지 않는다.
- 복사 시점에 본문이 사라졌거나 변환 결과가 비어 있으면 `복사 실패`를 표시한다.
- Clipboard API가 허용되지 않으면 브라우저가 지원하는 로컬 DOM 복사를 한 번 더 시도한다.
- SPA 이동이나 화면 재렌더 후에도 적용 조건이 유지되면 버튼을 다시 배치한다.

## 수용 기준

- 지원하는 Confluence 문서 조회 화면에서 `본문 Markdown 복사` 버튼을 발견할 수 있다.
- 버튼을 한 번 누르면 문서 제목과 댓글을 제외한 본문이 클립보드에 들어간다.
- 제목, 목록, 표, 코드 블록이 포함된 일반 문서를 Markdown 편집기에 붙여넣었을 때 해당 구조를 식별할 수 있다.
- 복사 중, 성공, 실패 상태가 버튼 문구로 표시되고 잠시 뒤 원래 문구로 돌아온다.
- 문서 사이를 이동하거나 화면이 다시 렌더링되어도 버튼이 중복되지 않는다.
- 기능 또는 Confluence 서비스 전체 기능을 끄면 버튼이 제거되고, 다시 켜면 적용 조건을 만족하는 화면에서 복구된다.
- 기능이 본문을 확장 저장소나 외부 서버에 저장·전송하지 않는다.
- typecheck, unit test, production build가 성공한다.

## 알려진 리스크와 열린 질문

- Confluence의 `data-testid`, renderer class 또는 상단 작업 영역이 바뀌면 기능 위치와 본문 탐지가 깨질 수 있다.
- Smart Link, Jira embed, 사용자 멘션, 펼치기, 상태, 첨부파일, 서드파티 매크로는 일반 텍스트나 링크로 축약되거나 누락될 수 있다.
- 로그인 권한이 필요한 이미지 URL은 Markdown에 포함되어도 다른 환경에서 표시되지 않을 수 있다.
- 병합 셀과 복잡한 표는 GFM 표 표현 범위를 넘어 정보가 단순화될 수 있다.
- 향후 제목이나 문서 링크를 함께 복사하는 별도 동작이 필요한지는 확정하지 않았다.

## 변경 이력

- 2026-08-07: Confluence 문서 조회 화면의 본문만 Markdown으로 복사하는 첫 기능 계약을 추가했다. 일반 복사 후 반복되는 서식 정리를 줄이고 API 인증 없이 현재 화면을 활용하기 위해 도입했다.
- 2026-08-07: 스크롤용으로 복제된 표 헤더가 별도 Markdown 표로 중복 복사되지 않도록 보조 표 판별을 추가했다. 실제 본문이 사이에 있는 정상 표는 유지한다.
- 2026-08-07: 본문 Markdown 복사 버튼을 상단 작업 영역의 오른쪽 끝으로 옮기고 복사 아이콘을 추가해 발견성과 의미 전달을 개선했다.
