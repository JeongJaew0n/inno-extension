# 아이콘 후보

**여기 있는 것은 아직 아이콘이 아니다.** 쓸지 말지 판단하려고 모아둔 것이다.

실제로 쓰는 아이콘은 `public/icons/` 하나뿐이고, `manifest.json` 의 `icons` · `action.default_icon`
이 그것을 가리킨다. **이 폴더의 파일을 거기로 옮기기 전까지 제품은 아무 영향도 받지 않는다.**

## 빌드에 걸리지 않는다

`public/` 아래에 두지 않는 이유가 이것이다. `public/` 은 내용이 통째로 `dist/` 로 복사돼
후보 이미지 한 장이 확장 ZIP 을 몇 배로 불린다. 실제로 그렇게 됐던 적이 있다.

| 경로 | 이 폴더를 보나 |
| --- | --- |
| Vite `publicDir` (`public/`) | **안 본다** |
| Vite 번들 | `manifest.json` 진입점만 따라간다 — **안 본다** |
| `scripts/package-extension.mjs` | `dist` 만 ZIP 에 담는다 — **안 본다** |

## 구성

후보 하나가 폴더 하나다.

```
<후보 이름>/
  source.png       원본. 손대지 않은 것
  preview-128.png  ─┐
  preview-48.png    │ 실제 아이콘 크기로 줄인 것
  preview-32.png    │
  preview-16.png   ─┘
```

**판단은 preview 로 한다.** 원본에서 좋아 보이는 그림이 16px 에서 뭉개지는 일이 흔하다.
브라우저 툴바에 실제로 뜨는 크기는 16 · 32 다.

미리보기를 다시 만들려면:

```
for s in 128 48 32 16; do
  sips -Z $s --setProperty format png <후보>/source.png --out <후보>/preview-$s.png
done
```

### `mascot-wave` 16px 측정

배경에 합성한 뒤 배경색과의 휘도 차이를 픽셀별로 쟀다. `뚜렷한 픽셀` 은 차이가 32 를 넘는
픽셀의 비율이다.

| 크기 | 배경 | 최대 대비 | 뚜렷한 픽셀 |
| --- | --- | ---: | ---: |
| 16px | 밝은 툴바 | 76 | **10.5%** |
| 16px | 어두운 툴바 | 213 | 54.7% |
| 48px | 밝은 툴바 | 189 | 19.7% |
| (참고) 현재 아이콘 16px | 밝은 툴바 | 107 | 37.5% |

**어두운 툴바에서는 문제없다. 밝은 툴바가 문제다.** 흰 몸통에 옅은 회색 외곽선이라, 16px 로
줄이면서 외곽선이 배경과 평균돼 거의 흰색이 된다. macOS Chrome 툴바는 기본이 밝은 쪽이다.

채택하려면 16 · 32 를 원본에서 줄이지 말고 **얼굴만 크게 잘라 따로 만드는** 편이 낫다.
`manifest.json` 은 크기별로 다른 파일을 가리키므로 그렇게 해도 된다.

## 채택할 때

`public/icons/` 의 네 파일(16 · 32 · 48 · 128)을 바꾸면 끝이다. `manifest.json` 은 고치지 않는다.
경로가 그대로이기 때문이다.

**바꾸기 전에 지금 것을 이 폴더에 후보로 남긴다.** 되돌리고 싶어질 때 원본이 없으면 곤란하다.
