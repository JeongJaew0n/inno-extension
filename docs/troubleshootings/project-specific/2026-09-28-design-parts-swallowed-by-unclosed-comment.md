# 디자인 조각을 이어 붙이면 첫 조각 뒤가 안 먹는다

- 발생일: 2026-09-28
- 상태: **원인 확정 · 수정 · e2e 로 확인**

## 증상

- 지난 스프린트 패널의 카드가 브라우저 기본 버튼 모양(회색 테두리)으로 보였다.
- `클릭 편집 방지` 스위치가 스위치가 아니라 기본 체크박스로 보였다.
- 숨긴(`hidden`) `편집` 버튼이 계속 보였다.

오류 메시지는 없다. CSS 가 조용히 버려진다.

## 원인

`design/generate-parts.py` 가 `components.css` 를 `@part` 표식 위치에서 잘랐다. 표식은 구역
머리말 주석 **안**에 있어서, 그 앞의 `/* ====` 줄이 **앞 조각 끝에 딸려 들어갔다.** 모든 조각이
닫히지 않은 주석으로 끝났다.

```
BUTTON_CSS = `.inno-btn{…}…\n/* ====`      ← 닫히지 않은 주석
TOGGLE_CSS = `.inno-switch{…}…\n/* ====`
```

기능이 `<style>${BUTTON_CSS}${TOGGLE_CSS}.row{…}</style>` 처럼 이어 붙이면 `BUTTON_CSS` 끝의 `/*`
가 **뒤를 전부 주석으로 삼킨다.** 실제 CSSOM 에서 규칙이 `.inno-btn--error` 에서 끊기는 것을
확인했다.

첫 조각만 쓰는 기능은 멀쩡해서 드러나지 않았다. 실제 Jira 에서 `업무 링크 복사`를 쟀을 때도 첫
조각인 버튼만 봤다.

| 기능 | 이어 붙인 것 | 실제로 먹던 것 |
| --- | --- | --- |
| 지난 스프린트 패널 | PANEL · BOARD · BUTTON · BADGE · STATUS | PANEL 만 |
| 클릭 편집 방지 | BUTTON · TOGGLE + 레이아웃 | BUTTON 만 |
| 링크 복사 · MR/PR 제목 복사 | BUTTON + 간격 | 간격 버려짐 |
| 설명 저장·취소 | BUTTON + 줄 배치 | 줄 배치 버려짐 |

## 해결

다음 구역 **머리말 주석이 시작하는 곳**(`rfind('/*', …)`)에서 끊는다. 조각에 주석이 남으면 생성이
실패하게 했다.

## 재발 방지

- 단위 테스트: 모든 조각에 `/*` · `*/` 가 없고 중괄호 짝이 맞는지 본다.
- e2e: 주입된 모든 `<style>` 의 주석 짝을 검사한다. 스위치·카드·숨김 버튼의 계산된 스타일도 본다.
