# 사후 기록

되돌아보기 위한 폴더다. 실제로 무언가 망가졌거나, 판단이 틀렸거나, 뒤늦게 원인을 찾은 일을 남긴다.

## 왜 남기는가

같은 실수를 두 번 하지 않기 위해서다. 코드는 고치면 흔적이 사라지지만, **왜 그렇게 만들었고 왜 그게 문제였는지**는 코드에 남지 않는다. 특히 다음 두 가지를 기록한다.

- 트리거와 근본 원인의 구분. 방아쇠를 당긴 변경과, 그 변경이 아니었어도 언젠가 터졌을 구조는 다르다.
- 진단 경로. 무엇을 먼저 확인했어야 빨랐는지가 다음 사고에서 시간을 아낀다.

## 작성 규칙

- 파일명은 `YYYY-MM-DD-짧은-제목.md`로 한다.
- **확인된 사실과 추정을 섞지 않는다.** 증거로 뒷받침되지 않는 부분은 추정이라고 명시한다.
- 원인을 사람이 아니라 구조에서 찾는다. 다만 판단 착오가 있었다면 그것도 숨기지 않는다.
- 재발 방지책은 "주의하겠다"가 아니라 코드·테스트·문서 중 하나로 남긴다.
- 해결되지 않은 항목은 열린 상태로 남긴다.
