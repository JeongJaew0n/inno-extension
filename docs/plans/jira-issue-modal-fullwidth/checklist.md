## 1. 스타일

- [ ] `html[data-inno-jira-wide]` 아래에서만 동작하는 규칙으로 작성
- [ ] `[data-testid*="issue-modal.modal-dialog"]`에 `width`·`max-width` 해제 (`!important` 필요)
- [ ] **원자 클래스(`._1bsb1osq` 등)를 선택자로 쓰지 않는다.** 빌드마다 해시가 바뀐다
- [ ] 스타일 시트는 한 번만 주입하고 토글은 속성만 바꾼다

## 2. 토글 버튼

- [ ] `사이드바로 전환` 버튼 왼쪽에 주입

- [ ] 기존 버튼 4개의 순서·동작을 건드리지 않는다
- [ ] 모달이 닫혔다 다시 열려도 상태 유지
- [ ] 같은 `data-testid`가 3개이므로 앵커는 `role="dialog"` 기준으로 찾는다
