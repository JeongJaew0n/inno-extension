## 1. 스타일

- [x] **상하 여백까지 해제** — 위치 컨테이너의 `top`·`bottom` 오프셋을 0으로. `height`만 늘리면 아래로 넘친다
- [x] 본체 높이는 `100vh`. `100%`는 본문 전체 높이(15688px)까지 늘어나 금지

- [x] `html[data-inno-jira-wide]` 아래에서만 동작하는 규칙으로 작성
- [x] `[data-testid*="issue-modal.modal-dialog"]`에 `width`·`max-width` 해제 (`!important` 필요)
- [x] **원자 클래스(`._1bsb1osq` 등)를 선택자로 쓰지 않는다.** 빌드마다 해시가 바뀐다
- [x] 스타일 시트는 한 번만 주입하고 토글은 속성만 바꾼다

## 2. 토글 버튼

- [x] `사이드바로 전환` 버튼 왼쪽에 주입
- [x] Shadow DOM host로 격리 (다른 사이트 기능과 동일)
- [x] 기존 버튼 4개의 순서·동작을 건드리지 않는다
- [x] 모달이 닫혔다 다시 열려도 상태 유지
- [x] 같은 `data-testid`가 3개이므로 앵커는 `role="dialog"` 기준으로 찾는다
