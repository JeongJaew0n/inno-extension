## 5. 키 처리 — 가장 위험한 부분

- [x] 목록이 닫혀 있으면 아무것도 하지 않는다 — Jira 의 이슈 생성을 막으면 안 된다
- [x] `stopPropagation` 으로 부족하면 capture 단계에서 처리
- [x] `↓` `↑` `Tab` `Esc` 처리
- [x] **IME**: `event.isComposing` 과 `keyCode === 229` 확인. 조합 중에는 필터를 갱신하지 않는다
