## 현재 블로커

- 사용자 승인 전에는 제품의 보안 경계와 원격 write 범위를 확정할 수 없다.
- 원본 폴더에 Git history가 없어 직접 복사할 코드의 provenance를 폴더만으로 확인할 수 없다.
- 이미지와 Mermaid는 공식 REST API만으로 보장되지 않아 실제 사내 tenant 검증이 필요하다.
