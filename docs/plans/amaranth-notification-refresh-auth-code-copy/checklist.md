## 남은 작업 메모

- Chrome 보안 정책상 `chrome://extensions` 관리 화면을 자동 조작할 수 없어, 빌드된 `dist`를
  현재 설치된 개발용 확장에 재로드하는 실제 사이트 검증은 남아 있다.
- 로컬 Chrome 하네스에서는 날짜 행 우측 배치, 4/5/6자리 및 선행 0 복사, WBlock 연도와
  메일 외 알림 제외, 클릭 전파 차단, `메일 → 전체` 왕복, 중복 없는 재주입, 기능 OFF/ON을 확인했다.
- 실제 사이트에서는 확장 재로드 후 새 메일 도착 전후 갱신, 팝업 닫기/열기, 읽음 상태 유지,
  기존 출퇴근·제목 자동채움 회귀를 최종 확인해야 한다.
- 기존 작업 트리에 있던 Confluence 변경은 수정하거나 되돌리지 않았으며 커밋도 수행하지 않았다.
