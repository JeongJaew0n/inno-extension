# 맥락 — 아마란스 자동채움 양식별 문구

## 요청 (2026-10-01)

> 아마란스 '자동채움' 기능, 신청서 양식별로 자동채움 설정할 수 있도록 해주고, '자동채움' 버튼 왼쪽에
> 모달 오픈 버튼 하나 둬서 그거 열면 자동채움 내용 설정할 수 있도록 해줘.

## 실측 (2026-10-01, gw.innogrid.com 근태신청서)

- 양식 카드: 근태일정, 연차휴가신청서, 외근신청서, 출장신청서, 교육신청서, 휴일/주말근무신청서,
  경조휴가신청서, 기타휴가신청서, 출산및육아휴직신청서, 휴직신청서
- 작성 화면(신청정보)에는 `제목` 이 없다. `신청완료` 뒤의 **상신정보** 표에 `제목`(`#text4`)이 나오고,
  기존 자동채움 버튼은 거기 붙는다. 이 단계에서도 왼쪽 카드의 선택 표시는 유지된다.
- 선택 카드: `li > div.selectedList`(한 개뿐) → `.tbl-tdl` 텍스트가 양식 이름.
- 결재라인 칸에도 `(신)연차휴가신청서 결재라인` 같은 문구가 있지만 사용자가 바꿀 수 있어 쓰지 않는다.

## 결정

| 결정 | 이유 |
| --- | --- |
| 기존 `titleText` 를 기본 문구로 유지 | 기존 사용자 설정을 옮기지 않아도 그대로 동작한다. 키 이름을 바꾸면 저장값을 잃는다 |
| 모달은 Shadow DOM | 아마란스 버튼은 표 안이라 light DOM 이지만, 모달은 body 에 따로 띄우므로 사이트 스타일과 섞일 이유가 없다 |
| Popup 은 상수 목록 + 저장 키 | Popup 에서는 화면을 볼 수 없다 |
