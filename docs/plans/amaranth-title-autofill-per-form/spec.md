# 계획 — 아마란스 자동채움 양식별 문구

## 만드는 것

1. 자동채움 문구를 **신청서 양식별로** 저장한다. 버튼은 지금 열린 양식의 문구로 제목을 채운다.
2. `자동채움` 버튼 **왼쪽에 설정 버튼(⚙)** 을 둔다. 누르면 모달이 열려 문구를 고치고 저장한다.
3. Popup 상세 설정도 같은 값을 양식별로 보여 준다.

## 데이터

`settings.sites.amaranth.features.titleAutofill.options`

| 키 | 뜻 |
| --- | --- |
| `titleText` (기존) | **기본 문구.** 양식별 문구가 없을 때 쓴다. 기존 사용자의 저장값이 그대로 여기 남는다 |
| `titleTextsByForm` (신규) | `{ "연차휴가신청서": "…", … }`. 빈 값은 저장하지 않는다 |

채울 문구 = `titleTextsByForm[현재 양식] || titleText`. 둘 다 비면 버튼은 비활성(기존과 같음).
문구 규칙은 기존과 같다 — 앞뒤 공백 제거, 190자.

## 현재 양식 읽기

실측(2026-10-01): 주소 hash 는 양식이 바뀌어도 `#/HP/HPD0110/HPD0110` 그대로다. 왼쪽 `근태신청서 양식 선택`
카드 목록(`[data-orbit-component="OBTCardList"]`)에서 **선택된 카드에만 `.selectedList`** 가 붙고,
그 안의 `.tbl-tdl` 이 양식 이름이다. 못 읽으면 기본 문구만 쓴다.

## 모달

```
자동채움 문구                                   ✕
현재 양식  연차휴가신청서  [_____________________]
기본 문구  (양식별 문구가 없을 때) [_____________]
▸ 다른 양식 (8)   — 펼치면 양식별 입력칸
                               [취소] [저장]
```

- 저장은 `chrome.storage.sync` 로 한다. Popup·다른 탭과 같은 값이다.
- Esc · 바깥 클릭 · 취소는 저장 없이 닫는다.
- 신청서를 제출하지 않는다. 모달은 제목 칸도 건드리지 않는다(채우기는 `자동채움` 버튼 몫).

## 양식 목록

모달은 화면의 카드 목록에서 이름을 읽는다(`근태일정` 은 신청서가 아니라 뺀다). Popup 은 화면을 볼 수 없으니
실측한 목록을 상수로 두고, 저장된 키가 더 있으면 함께 보여 준다.
