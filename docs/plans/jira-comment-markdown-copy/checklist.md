## 4. 실사용

- [x] 실제 Jira 댓글 복사 (2026-10-16, ego 브라우저). 확장 설치가 막혀 **같은 런타임 소스를 번들로 묶어 실제 페이지에 주입**했다. 패키지된 확장으로 본 것은 아니다
  - NPT-630: 댓글 5개에 버튼 5개, 모두 동작 줄 끝, 높이 24px(줄 28px). 복사 결과에 제목·목록·인라인 코드가 그대로
  - NPT-669: 이미지 댓글 `복사됨 · 이미지 1/1`, data URI 로 들어가고 토큰 주소는 남지 않음
  - 기존 댓글 편집을 열면 그 댓글 버튼만 빠지고, `취소` 로 닫으면 돌아옴. 아무것도 입력하지 않았고 저장하지 않았다
  - reconcile 이 계속 돌지 않는다(2초 동안 그대로)
  - 함께 본 기존 변환기 한계: 멘션(`@이름`)이 빠지고, 스마트 링크는 favicon 이미지가 링크 텍스트에 섞인다. 설명·Confluence 복사와 같은 변환기 문제라 여기서 고치지 않았다
