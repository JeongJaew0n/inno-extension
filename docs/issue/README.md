# 이슈 기록

관찰됐지만 아직 원인이 확정되지 않았거나, 확정됐어도 후속 조치가 남은 문제를 기록한다.

## 사후 기록과의 차이

| 폴더 | 대상 |
| --- | --- |
| `docs/postmortems/` | 이미 해결된 사고. 원인과 재발 방지를 정리한다 |
| `docs/issue/` | **진행 중이거나 미확정인 문제.** 관찰 사실과 확인해야 할 것을 정리한다 |

원인이 확정되고 조치가 끝나면 사후 기록으로 옮기거나, 여기서 해결 상태로 닫는다.

## 작성 규칙

- 파일명은 `YYYY-MM-DD-짧은-제목.md`로 한다.
- **관찰된 사실과 추정을 반드시 구분한다.** 재현하지 못했으면 못했다고 쓴다.
- 사용자가 보고한 원문을 그대로 남긴다. 요약하면 단서가 사라진다.
- 확인이 필요한 것을 명시적으로 남긴다. 다음 사람이 무엇을 물어야 하는지 알 수 있어야 한다.
