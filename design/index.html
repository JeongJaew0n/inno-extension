Inno Extension 디자인 시스템

Material 3 의 전략으로 짜고, 색은 Figma 조합 59 「요트 클럽」 네 색에서 뽑는다. 색을 하나씩 고르지 않는다 — 원천 색에서 색조 팔레트를 뽑고, 색조를 역할에 배정한다. 토큰은 손으로 쓰지 않고 design/generate-tokens.py 가 만든다.
제품에는 아직 적용하지 않았다. 확장 빌드와 완전히 분리돼 있어 ZIP 에 들어가지 않는다.

전략

색조 팔레트원천 #F2F0EF · #BBBDBC · #245F73 · #733E24 (요트 클럽). 주색·강조색은 원본을 그대로 앉히고, 여섯 팔레트를 계산한다
역할primary / on-primary / primary-container … 색이 아니라 쓰임을 가리킨다
표면 단계그림자 대신 surface-container-* 로 높이를 표현
상태 레이어hover·pressed 를 on-* 의 불투명도로 덮는다. hover 색을 따로 만들지 않는다
모양·타입·4dp 격자단계로 고정. 중간값을 쓰지 않는다

M3 가 쓰는 HCT 대신 CIELCh 로 같은 일을 한다. 색조를 L* 로 두고 색상·채도를 유지하되 sRGB 밖으로 나가면 채도를 이진 탐색으로 줄인다. 외부 라이브러리 없이 돌아간다.
타입 스케일은 M3 이름을 쓰되 크기를 줄였다. display·headline 은 앱 화면용이고 우리 UI 는 남의 화면에 얹히는 작은 조각이다.

버튼

hover 색이 따로 없다. 상태 레이어가 on-* 을 8% 덮는다. 눌렀을 때는 12%. 어떤 배경에 올려도 같은 규칙이 먹는다.
채운 버튼은 되돌릴 수 없는 동작에만 쓴다.

기본 (24px) — 주입 UI 대부분
32px — 편집기 툴바처럼 주변이 클 때만
아이콘만 — 남의 줄 사이에 끼는 자리 커밋 a1b2c3d

칩 · 배지

배지는 *-container 와 on-*-container 짝을 쓴다.
칩은 min-width: 0 이 핵심이다 — 풀지 않으면 flex 안에서 내용 폭으로 버티다가 바깥에서 잘리고, 말줄임도 자기가 넉넉한 줄 알고 작동하지 않는다. 실제로 그 버그를 겪었다.
