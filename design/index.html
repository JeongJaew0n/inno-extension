Inno Extension 디자인 시스템

제품에는 아직 적용하지 않았다. 확장 빌드와 완전히 분리돼 있다 — tsconfig 는 src 만 보고 패키징은 dist 만 담으므로 이 폴더는 ZIP 에 들어가지 않는다.
React 를 쓰지 않는다. 우리 UI 는 Shadow DOM 에 평문 CSS 문자열을 넣기 때문에, 그대로 붙여넣을 수 있는 CSS 여야 쓸모가 있다.

왜 만드나

Jira·Confluence 와 안 맞는 것은 받아들인다. 우리 것이라는 게 티나도 괜찮다. 문제는 우리 기능끼리 서로 다른 것이다. 지금 같은 성격의 버튼이 높이 24px 과 32px, 글자 12px 과 13px, 모서리 3px 과 4px 로 제각각이고, 주입 UI 는 Atlassian 파랑을 Popup 은 보라를 쓴다. 색을 한 벌로 합치고 크기를 두 단계로 줄인다.

지금Markdown 변환 32px/13px · Markdown 복사 24px/12px · 저장 24px/12px · Popup 버튼 또 다름
여기.inno-btn 24px/12px 하나. 편집기 툴바처럼 주변이 클 때만 --md 32px/13px
